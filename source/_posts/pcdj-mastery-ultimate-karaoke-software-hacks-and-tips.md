## PCDJ Mastery: Ultimate Karaoke Software Hacks and Tips

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2014/06/importingkaraokefiles-coverimage.jpg?resize=573%2C263&ssl=1)](https://i2.wp.com/pcdj.com/wp-content/uploads/2014/06/importingkaraokefiles-coverimage.jpg?fit=573%2C263&ssl=1 "importingkaraokefiles-coverimage")

PCDJ’s **best karaoke software** solution for professional KJs and hard-core enthusiasts is [**PCDJ Karaoki**](https://tools.techidaily.com/pcdj/products/), a robust and feature packed karaoke application that’s now been available for purchase and download for 7 years. 

In this edition of “_**Tips and Tricks**_” we focus on importing your MP3+G, Zipped MP3+G and MP4 karaoke files into PCDJ Karaoki and explain what karaoke “**naming conventions**” are.

1. **MY LIBRARY: Creating A Case**[![MY Library PCDJ Karaoki](https://pcdj.com/wp-content/uploads/2014/05/mylibrary-image1.jpg)](https://pcdj.com/wp-content/uploads/2014/05/mylibrary-image1.jpg)  
_Launch/Open PCDJ Karaoki. Click on “**My Library**” – this is where all your own custom cases of karaoke music can be created, and where you would import your own karaoke music into PCDJ Karaoki._
2. **ADD CASE: Create Your First Karaoke Music Group**[![add case PCDJ Karaoki](https://pcdj.com/wp-content/uploads/2014/05/addcase-image2.jpg)](https://pcdj.com/wp-content/uploads/2014/05/addcase-image2.jpg)  
_Click “**Add Case**” in the bottom left corner of the Karaoki skin/interface. Clicking Add Case will pull up a dialog box where you can type in a name of your choice._
3. **NAME YOUR CASE: Any Name Will Do, Your Choice**[![PCDJ Karaoki - Name Case](https://pcdj.com/wp-content/uploads/2014/05/typeinnameofcase-image3.jpg)](https://pcdj.com/wp-content/uploads/2014/05/typeinnameofcase-image3.jpg)_Type in the name of your case and click “**OK**” to create it. This will create the case as a subtab under “**My Library**“_  
_**Example:**_  
[![casehasbeencreated-image4](https://pcdj.com/wp-content/uploads/2014/05/casehasbeencreated-image4.jpg)](https://pcdj.com/wp-content/uploads/2014/05/casehasbeencreated-image4.jpg)
4. **ADD SONGS: Now To Import Files Into Your Case**[![addsongsscanfolder-image5](https://pcdj.com/wp-content/uploads/2014/05/addsongsscanfolder-image5.jpg)](https://pcdj.com/wp-content/uploads/2014/05/addsongsscanfolder-image5.jpg)_Once again, in the bottom left hand corner of the PCDJ Karaoki karaoke software interface, click on “**Add Songs**” and select from the pop up menu “**Scan Folder**“. This will bring up a “Browse For Folder” explorer window in the middle of PCDJ Karaoki._  
_**Example:**_  
[![browseforfolderwindow-image6](https://pcdj.com/wp-content/uploads/2014/05/browseforfolderwindow-image6.jpg)](https://pcdj.com/wp-content/uploads/2014/05/browseforfolderwindow-image6.jpg)  
_From the “**Browse For Folder**” explorer tree view, you can navigate your hard drive or any connected hard drive to locate a folder (or select the drive letter itself if you wish to import the entire contents of the drive) that contains your karaoke music. You only need to select the parent folder, as PCDJ Karaoki will import any song in any subfolder below the parent folder you’ve selected into your case._
5. **SELECT THE KARAOKE FOLDER/DIRECTORY YOU WISH TO IMPORT**[![selectfolderyouwanttoimport-image7](https://pcdj.com/wp-content/uploads/2014/05/selectfolderyouwanttoimport-image7.jpg)](https://pcdj.com/wp-content/uploads/2014/05/selectfolderyouwanttoimport-image7.jpg)  
_Make sure to click on the folder (or drive) of music you wish to import into your case (again, Karaoki will automatically import any songs in subfolders below the parent directory you’ve selected). Then click the “**OK**” button at the bottom of the “**Browse For Folder**” pop up explorer view._
6. **IMPORT SCREEN: Select The File Types You Want To Import**[![importscreen-image8](https://pcdj.com/wp-content/uploads/2014/05/importscreen-image8.jpg)](https://pcdj.com/wp-content/uploads/2014/05/importscreen-image8.jpg)  
_From the “**Scan Files**” pop-up menu you can select what file types you wish to import and more. By default, both “**Zip**” and “**MP3**” are checked off. These are standard karaoke file formats. However, if you have **MP4 karaoke files** or other file formats displayed on the “**Scan Files**” menu, you can check those off as well._  
_I also highly recommend checking off “**Only Add If Song Is Not In Case**” — this means that if you re-scan a directory into a case that’s already been previously scanned in, only NEW files added to that directory/folder will be displayed. If you do not check it, and scan the folder into a case again, you will get duplicates in your case._  
_Now, click “**Import Now**” to start scanning in your tracks from the selected directory/folder into your case. If you have a lot of files, this may take a few minutes. You will be presented with a counter on the “**Scan Files**” menu that will show you a real-time count of files as they are being imported._
7. **NAMING CONVENTIONS: Scan Songs Using “Naming Convention” or ID3 Tag Extraction**[![namingconventionyes-image9](https://pcdj.com/wp-content/uploads/2014/05/namingconventionyes-image9.jpg)](https://pcdj.com/wp-content/uploads/2014/05/namingconventionyes-image9.jpg)_As soon as your music is finished importing in your case, you will be presented with a “**Scan Case**” Dialog box as picturedabove. Click “**Yes**“_  
_Why do you have to select a proper “**naming convention**“? In the karaoke world, using file names are standard (instead of id3v2 tags or variations for DJ music). This is primarily due to the popularity of ZIP karaoke files (MP3+G files inside of a zip file), which do not support tags, only file names. All popular download sites, including our **[KaraokeLocker.com](http://www.karaokelocker.com)** website, sell zip files utilizing file names. For this reason, you want to make sure your file names are conformed, or at least as much as possible. So if you have “**DiscID-trackID – Artist – Title**” for instance, you want the same naming convention/file naming method for all your karaoke files._
8. **NAMING CONVENTIONS: Selecting The Proper Naming Convention**[![Selectnamingconventionthatmatchesfiles-image10](https://pcdj.com/wp-content/uploads/2014/05/Selectnamingconventionthatmatchesfiles-image10.jpg)](https://pcdj.com/wp-content/uploads/2014/05/Selectnamingconventionthatmatchesfiles-image10.jpg)  
_From the “**Extraction Method**” drop down box you want to select the naming convention that matches the way your file names are formatted. I suggest opening up the directory/folder of karaoke music on your drive to view the file names there. In my “**Chartbuster Karaoke**” folder as pictured above, my files are all labeled “**Title – Artist**” (with a space before and after the hyphen), so I will select that naming convention._  
_If you have files in folders that use different naming conventions, the best solution would be to create different cases in Karaoki for each different file naming method. This way you can use a different “**Extraction Method**” for each case, allowing your song information to properly display in the Karaoki case/library (**with Artist in Artist, and Title in Title etc**)_  
_You can also use “**Extract ID3 Tag**“. This is the last option in the “_ **_Extraction Method_**_“ drop down menu. This will only work with MP3 files that have ID3 Tags. This feature was added mainly due to older karaoke software PCDJ produced that worked exclusively with ID3 tags, before using file names was the broadly adopted file naming method for karaoke music._  
_Once you’ve selected the proper naming convention from the “**Extraction Method**” drop down menu that mirrors your file names in the directory you’ve imported, click “**Go**” — this will quickly rescan the case with the extraction method and if done properly, you should see your tracks in your case with **Artist displayed in the Artist field, and Title in Titl**e, etc._  
[![hitgo-image11](https://pcdj.com/wp-content/uploads/2014/05/hitgo-image11.jpg)](https://pcdj.com/wp-content/uploads/2014/05/hitgo-image11.jpg)
