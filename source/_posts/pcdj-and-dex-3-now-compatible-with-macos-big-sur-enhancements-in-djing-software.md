## PCDJ and DEX 3 Now Compatible with macOS Big Sur: Enhancements in DJing Software

[![macOS Big Sur DEX 3 DJ Software Support](https://i1.wp.com/pcdj.com/wp-content/uploads/2020/11/macOS-Big-Sur-800x450.jpg?resize=800%2C321&ssl=1)](https://i1.wp.com/pcdj.com/wp-content/uploads/2020/11/macOS-Big-Sur-800x450.jpg?fit=800%2C450&ssl=1 "macOS Big Sur DEX 3 DJ Software Support")

Apple’s new [macOS Big Sur](https://www.apple.com/macos/big-sur/) was released last Thursday and it comes with aesthetic and internal changes, including new Safari features, redesigned GUI, and new Control Centre/Notification Centre. With all the new changes, most DJ software creators are asking users to wait on upgrading to Big Sur.

[![](https://i2.wp.com/pcdj.com/wp-content/uploads/2020/10/macbook-pro-retina.png?fit=300%2C162&ssl=1 "DEX 3 DJ software with LINK streaming support")](https://tools.techidaily.com/pcdj/products/)

Unlike macOS Catalina, which did require DEX 3 DJs to wait on upgrading for a few weeks due to substantial updates to the graphics API, we’re happy to say you can upgrade at your desire — after extensive testing we’ve found DEX 3 to run great on macOS Big Sur!

If you haven’t already, [download and try the latest DEX 3.15 DJ software release](https://tools.techidaily.com/pcdj/products/) with macOS Big Sur, now with support for [Beatport LINK and Beatsource LINK](https://tools.techidaily.com/pcdj/products/).
